# NOIRKIT floor

Open the running rig at `/kit`. Section 00 is the board.

- **Effects.** Stepped grain, lamp flicker, vignette, and one red stamp.
- **Hover.** Stop, the stamp, an evidence marker, a suspect photo, and a case-file line. Each one lifts or brightens over 420ms. Nothing glows.
- **Transition.** Roll the tape. The picture leaves, a soft black tail passes, and the next title continues on the same strip. Sprocket holes ride with it. Press again and it rewinds.

`floor-tape.png` holds that roll in the black, with the next title coming up.
